Este programa permite calcular el total de una compra a partir del precio de un producto y la cantidad que lleva el cliente.

Para realizar el cálculo se utiliza una función llamada `calcular_total`, que recibe dos parámetros: `precio` y `cantidad`. La función multiplica estos valores y retorna el resultado.

Ejemplo:

Precio del producto: $10

Cantidad: 3

Total de la compra: $30

Archivo:

El proyecto contiene el archivo `calcular_compra.py`, donde se encuentra la función y su llamada desde el bloque principal del programa.
